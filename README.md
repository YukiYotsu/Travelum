# Travelum（みんなで旅しおり）

ログイン不要！合言葉だけで家族や友人と安全・リアルタイムに旅行計画・「行きたい！」リスト・旅程表を作れるグループ旅行アプリです。

## 主な機能
- **「行きたい！」リスト**: 「ごはん」「観光地」「その他（自由記述）」のカテゴリータグ付きで候補を共有＆「いいね」投票
- **日程別タイムライン（旅程表）**: 候補からワンタップで日程と時間を割り振り。端末内に自動キャッシュされるため、オフライン環境でも閲覧可能
- **現地タクシー提示カード**: 目的地の現地名称と住所を特大フォントで全画面表示し、運転手にそのまま見せて移動可能
- **ペンギン権限管理（荒らし対策）**: 部屋の作成者（Leader Penguin）が参加メンバーの編集権限（Assistant / Viewer）を管理可能
- **連絡チャット**: ルームメンバー間でリアルタイムにメッセージやり取り
