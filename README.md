# Travelum（みんなで旅しおり）

ログイン不要！合言葉だけで家族や友人と安全・リアルタイムに旅行計画・「行きたい！」リスト・旅程表・旅費割り勘を作れるグループ旅行アプリです（iOS / iPadOS 対応）。

## 主な機能（ver2.0）

- **合言葉ルーム＆3段階の権限管理**
  - アカウント登録・電話番号不要。ランダム生成または任意の合言葉で即座にルームを作成・参加可能。
  - `👑 リーダー（管理者）` / `🐧 編集メンバー` / `🐣 閲覧のみ` のロール管理と新規参加ロック機能。
- **「行きたい！」リスト＆投票**
  - カテゴリー分け（ごはん・観光地・移動・カスタムタグ）、いいね投票、追加順／日程順／いいね順／未定のみの並び替え。
- **旅程表＆スマート移動ルート提案**
  - 1分単位の時刻設定・数字パッド入力、現地タイムゾーン選択（夏時間・DST自動判定）。
  - 連続する予定間の移動手段（電車・バス／タクシー・車／自転車／徒歩）の所要時間・出発目安を自動計算し、ワンタップで旅程へ追加。
- **旅費・割り勘自動計算**
  - 各予定に立替金額と支払者を記録し、合計金額・1人あたり目安・メンバー別の精算差額を自動算出。
- **ハイブリッド連絡チャット（Mesh ＋ Net）**
  - **Mesh（Bluetooth / Wi-Fi Direct）**：電波がない場所や機内・海外でも、近くの端末同士でバケツリレー中継・すれ違い再送が可能（合言葉ベースの AES-GCM 256bit 暗号化・バックグラウンドBLE対応）。
  - **Net（オンライン同期）**：インターネット経由でのリアルタイム同期およびオフライン送信待ちキュー（Outbox）からの自動再送。
  - 通信方式（`Mesh` / `Net`）と送達確認（`送信済` / `送信待ち`）のステータス表示。
- **安全機能・通知**
  - 不適切な投稿の通報・ユーザーブロック機能、新着チャット・メンバー参加/退出のローカル通知＆バッジ表示。

## セットアップ（ビルド方法）

公開リポジトリには接続先キー保護のため `AppEnvironment.swift` を含めていません。ビルドする際は以下の手順で設定ファイルを作成してください。

1. `AppEnvironment.example.swift` を複製し、ファイル名を `AppEnvironment.swift` に変更します。
2. `AppEnvironment.swift` 内の `projectURL` と `publishableKey` にご自身の Supabase プロジェクト情報を入力します。
3. Xcode または Swift Playgrounds でプロジェクトを開いてビルドします。
